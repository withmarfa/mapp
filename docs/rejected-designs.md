# Rejected designs

Status: Reference. Each design below was drawn and turned down.

Where it lives: this page records choices that have no code to show for them. The pages it links to describe what MAPP does instead.

Do not try one of these again in the same form. If a new case needs one, say what is different and ask first.

## Chips and values

- **A type in a neutral chip with a gray edge.** A tint means a type; see [Value components](value-components.md).
- **A tag drawn with the tag symbol or an outline.** A tag is gray, after a number sign.
- **A person in a gray chip.** A person is initials in a pale circle, with no chip and no edge.
- **Glass type marks with a drop shadow.**
- **A chip taller than its neighbors.** Chips side by side must line up, so every chip is one height.
- **Chips squeezed to a few letters.** Fit whole chips, then show "+N".
- **A person drawn smaller than the chips beside it.**
- **A bordered plus button for an empty value.** An empty value is the gray word Empty.
- **Bare chips.**
- **Pen-style highlights.** Highlights are yellow, with other colors as settings.

## The item page

- **Pins each in a box with a fill, or as one strip with hairlines.**
- **Larger text in pins.**
- **A placeholder for a pin that has no value**, such as a dotted place or a "drop a pin" box, in Customize Layout or on the page.
- **Customize Layout from a menu on each row**, or Customize Page in a sheet. It is the right sidebar. See [Item page](item-page.md).
- **A "when" band** above the title or between the properties, and a line of text between the title and the pins.
- **Accent rails on callouts**, and any side rail except on a quote block.
- **Dividers that run to the edges of a grouped box.**
- **Centered headers.**
- **Blue links for maps and places.**
- **Empty frames where a picture belongs.**

## Rows, cards and views

- **A status and a type's mark sharing one leading column of a row.**
- **A type shown twice in one row**, as a mark and as a chip.
- **Blank space hanging under a row's leading mark.**
- **A type tile at the trailing edge of a row, or a large leading type tile.**
- **A person's name in a row.** A row shows initials only.
- **A clipboard item titled with its content.** It is titled "Clipboard Item", or a name its person gave it.
- **A gray key, such as a number, before a title.** A number is a property.
- **Sources as cards with a type breakdown bar.**
- **Gallery text centered under the card, or over the picture.**
- **Gallery cards too wide or too tall, and pictures at landscape height.**
- **A board without its columns.**
- **An agenda narrowed to a column.** The timeline uses the window's width.
- **A thumbnail column of a new kind beside a document.**
- **A flat, squared or hand-drawn segmented control.** MAPP uses the system's. See [Views and lists](views-and-lists.md).
- **A separate filter button in the list toolbar.** Filters live in the row above the list.
